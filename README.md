##  О программе

**PhotoRave** — это мощное, но простое в использовании приложение для работы с изображениями. Создано для тех, кто ценит своё время и хочет получать профессиональный результат без сложных настроек и необходимости подключения к интернету.

Полностью офлайн-инструмент, который работает сразу после установки и не требует регистрации или отправки ваших файлов на сторонние серверы. Все данные остаются только на вашем компьютере.

---

##  Возможности

###  Конвертер форматов
- Поддержка всех популярных форматов: **PNG, JPG, ICO, BMP, GIF**
- Пакетная обработка нескольких файлов одновременно
- Сохранение исходного качества изображения
- Drag & Drop — просто перетащите файлы в окно программы

###  Закругление углов
- Создание идеальных иконок с закругленными углами
- Настраиваемый радиус закругления (от 0 до 200px)
- Автоматическое создание ICO файлов с несколькими размерами (16x16 до 256x256)
- Дополнительные эффекты: тень, рамка, свечение
- Сохранение в PNG с прозрачностью

### Несколько размеров
- Создание различных версий одного изображения за один клик
- Готовые пресеты: иконки 16x16, 32x32, 48x48, 64x64, 128x128, 256x256
- Веб-размеры: 300x200, 600x400, 1024x768
- Автоматическое центрирование изображения
- Сохранение пропорций

##  Интерфейс программы

### Главное меню
При запуске вас встречает стильное главное меню с тремя основными разделами:

- ** Конвертер** — для изменения формата изображений
- ** Закругление** — для создания иконок с закругленными углами
- ** Несколько размеров** — для создания различных размеров изображений

### Простота использования
1. Выберите нужную функцию в главном меню
2. Перетащите файлы мышкой в окно программы
3. Настройте параметры под свои задачи
4. Нажмите "Начать обработку"
5. Готовые файлы сохранятся в отдельную папку

---

##  Как использовать

### Конвертер форматов
1. Нажмите кнопку **"Конвертер"** в главном меню
2. Перетащите изображения в окно или выберите через кнопку "Выбрать файлы"
3. Выберите целевой формат (PNG, JPG, ICO, BMP, GIF)
4. При необходимости настройте качество для JPG
5. Нажмите "Начать обработку"
6. Укажите папку для сохранения
7. Готово! Все файлы сконвертированы

### Закругление углов
1. Нажмите кнопку **"Закругление"** в главном меню
2. Добавьте изображения
3. Настройте радиус закругления (чем больше значение, тем сильнее закругление)
4. При желании добавьте эффекты: тень, рамку, свечение
5. Выберите качество сохранения
6. Нажмите "Начать обработку"
7. Для каждого файла создастся отдельная папка с PNG и ICO версиями

### Несколько размеров
1. Нажмите кнопку **"Несколько размеров"** в главном меню
2. Добавьте изображения
3. Выберите нужные размеры из списка
4. Настройте качество
5. Нажмите "Начать обработку"
6. Для каждого исходного файла создастся папка со всеми выбранными размерами

## ❓ Часто задаваемые вопросы

### Какие форматы поддерживаются?
Программа работает с PNG, JPG, BMP, GIF, ICO.

### Можно ли обработать несколько файлов сразу?
Да, программа поддерживает пакетную обработку. Вы можете выбрать сколько угодно файлов и обработать их за один раз.

### Нужен ли интернет для работы?
Нет, программа полностью автономна и не требует подключения к интернету.

### Сохраняется ли качество изображений?
Да, при конвертации и обработке используется максимальное качество (настраивается пользователем).

### Куда сохраняются обработанные файлы?
При каждой обработке программа создает отдельную папку с датой и временем, чтобы файлы не перезаписывались.

### Как удалить программу?
Если вы устанавливали через установщик, используйте "Установка и удаление программ" в Windows или запустите `unins000.exe` в папке с программой.
